# /nona-prompter

Пишет промпты для Seedance и Kling по ТЗ рекламного или UGC-ролика.

## Как пользоваться

1. Напиши `/nona-prompter`, укажи стиль (UGC, студийная съёмка, Pixar и т.п.) и вставь ТЗ по шотам.
2. Если у персонажей уже есть карты, а для липсинка готово аудио, скажи об этом сразу.
3. Получишь ссылку на схему: **Персонажи → Первые кадры → Видео**.

## Что умеет схема

- Промпты можно править прямо в карточках, правки сохраняются сами.
- Кнопка «Копировать» копирует промпт с готовыми ссылками `Image1`, `Image2`… Над промптом есть легенда: какую картинку грузить под каким номером.
- Галочка «сгенерировано» сворачивает карточку. В шапке виден прогресс и сколько генераций осталось.
- При наведении на карточку подсвечивается вся цепочка: персонаж → кадр → видео.
- Тот, кому ты отправил ссылку, видит доску только для чтения.

## Правила промптов (коротко)

- Видео-промпт: первый кадр → действия → звук → камера, блоки через пустую строку.
- Свет, одежду, внешность и локацию в видео-промпт не пишем, они уже есть в первом кадре.
- Липсинк: реплика дословно из ТЗ и `[audio] as audio, lip sync matches the speech.`
- Ч/б и прочие пост-эффекты в промпты не попадают, они помечаются тегом.

## Обучение

Когда закончишь проект, попроси: «сравни первую и последнюю версию схемы». Claude найдёт твои правки и предложит новые правила для скилла.
